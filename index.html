Sources, coverage & limitations

This is department course exploration, not a degree audit. Grade requirements, placement tests, permissions, mixed prerequisite alternatives, course availability and track approval may need manual review. “Listed course checks met” refers only to the rules we can check against what you entered.

Semantic matching uses the pretrained all-MiniLM-L6-v2 sentence encoder with cosine similarity. The first use downloads a model of about 23 MB from this site. Keyword matching uses TF-IDF or BM25. Comparison mode ranks the same candidate pool with all three models; scores use different scales and are not probabilities or measured accuracy.

Fun is personal; no claims about grades, difficulty, workload or current availability are verified. Plans stay in this browser session; download one to keep it. Student feedback and labeled recommendation-quality evaluation have not been completed.
